# Draftline visual system

Draftline is a studio operating system for a solo producer coordinating clients, editors, budgets, and deadlines. It uses a restrained, high-contrast palette so data stays scannable while the amber/cobalt pairing makes money and action immediately distinct.

- **Mode:** Operate
- **Canvas:** Graphite sidebar and pale mineral workspace in light mode; near-black canvas and lifted charcoal panels in dark mode.
- **Typography:** Space Grotesk for headings and figures, DM Sans for controls and supporting copy.
- **Color roles:** Cobalt is for active navigation and primary actions. Amber marks money, dates, and attention. Mint is success. Rose is reserved for future risk states.
- **Composition:** A persistent command frame; split first viewport (weekly pulse + take-home), then action queue and project ledger. Detail surfaces use tables rather than decorative card stacks.
- **Motion:** Chart bars grow from the baseline once; hover and action feedback stays short and state-based. Reduced-motion users receive no authored animation.
